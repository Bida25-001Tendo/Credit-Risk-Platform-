# Credit Risk Management Platform – Power BI 
This folder contains the access link to the Power BI dashboard developed as part of the Credit Risk Management Platform project.The dashboard integrates the outputs of the Probability of Default (PD) model with portfolio-level credit risk analysis. It provides an interactive view of borrower risk and overall loan portfolio performance, supporting credit risk assessment and monitoring.

## How to Access the Power BI Dashboard
